# To-Do List Web Application

This project is a simple CRUD application for a To-Do List using the MVC pattern in C# .NET Core.

## Features

- **View To-Do List:** Users can view a list of existing To-Do items.
- **Create To-Do Items:** Users can create new To-Do items.
- **View Details:** Users can view details of a specific To-Do item.
- **Edit To-Do Items:** Users can edit existing To-Do items.
- **Delete To-Do Items:** Users can delete To-Do items after confirmation.
